# A projekt alapjai

Ez kitöltendő projektadatlap, nem egy már létező alkalmazás specifikációja.
A még nem egyeztetett adatot az agent ne találja ki. A parancs csak helyi
ellenőrzés után kerüljön az „ellenőrzött” oszlopba.

| Adat | A projekt saját értéke |
| --- | --- |
| Név és cél | Még nincs kitöltve |
| Felhasználók és fő feladatuk | Még nincs kitöltve |
| Technológia és támogatott verziók | Még nincs kiválasztva |
| Fontos könyvtárak | Az alkalmazás hozzáadásakor kitöltendő |
| Követelmények felelőse | A csapat jelöli ki |
| Review és kiadás menete | A csapat határozza meg |
| Projektkorlátok | Csak egyeztetett korlát kerüljön ide |

| Feladat | Parancs | Ellenőrzött környezet és dátum |
| --- | --- | --- |
| Build | Még nincs megadva | Még nincs ellenőrizve |
| Tesztek | Még nincs megadva | Még nincs ellenőrizve |
| Formázás / lint | Még nincs megadva | Még nincs ellenőrizve |
| Helyi indítás | Még nincs megadva | Még nincs ellenőrizve |

Kotlin/Gradle projektben például a projekt saját Gradle wrapperét használjuk.
Ez példa, nem a starter által telepített vagy már ellenőrzött parancs.
A forráskód helyét és a buildrendszert az új alkalmazás igénye határozza meg.
